AI-Based Smart Attendance System Using Face Recognition
Overview

An AI-powered attendance management system that uses computer vision and face recognition to automate attendance tracking in real time.

Features
Real-time face detection
Automated attendance marking
Attendance dashboard
User authentication
Report generation
Duplicate attendance prevention
Web-based interface
Technologies Used
Python
OpenCV
Django
Haar Cascade
LBPH Algorithm
SQLite / MySQL
HTML
CSS
JavaScript
System Workflow
Capture facial image
Detect face using Haar Cascade
Extract features using LBPH
Match with trained dataset
Mark attendance automatically
Store attendance records in database
